## Current project

**[Tomb Tale Platform](https://github.com/cingiskagan/tomb-tale-platform)** is an open-source platform backend for an online RPG. It handles player accounts, purchases and inventory as Spring Boot microservices. The services communicate over RabbitMQ with at-least-once delivery and idempotent consumers. Keycloak handles authentication. An Angular admin portal lets admins browse players and purchases. More than 160 tests run against real PostgreSQL, RabbitMQ and MongoDB instances with Testcontainers.
